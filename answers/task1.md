# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
2. 编译
3. 汇编
4. 链接

建议控制在 300～500 字，不需要展开复杂细节。

1. 预处理 .c -> .i
处理所有`#`开头的指令,包括展开头文件、替换宏定义,生成**纯C语言代码**

2. 编译 .i -> .s
对预处理后的代码进行词法分析、语法分析和语义检查，确认无误后将其翻译为**汇编语言**

3. 汇编 .s -> .o
将汇编代码逐条转换为**二进制机器指令**，生成可重定位目标文件

4. 链接 .o -> 可执行程序代码
合并所需的库文件,核心工作是符号解析(匹配函数/变量引用)和重定位(修正地址引用)
