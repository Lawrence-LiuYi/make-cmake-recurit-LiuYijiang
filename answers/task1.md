# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
2. 编译
3. 汇编
4. 链接

建议控制在 300～500 字，不需要展开复杂细节。

1. 预处理 .c -> .i
处理所有 `#` 开头的指令，包括展开头文件、替换宏定义、处理条件编译，并删除注释，生成**纯 C 源代码**的 .i 文件

2. 编译 .i -> .s
对预处理后的代码进行词法分析、语法分析和语义检查，确认无误后将其翻译为**汇编语言**

3. 汇编 .s -> .o
由汇编器将汇编代码逐条翻译为**二进制机器指令**，同时处理标号地址、生成符号表和重定位表，输出可重定位目标文件 .o；
此时各段地址尚未最终确定，文件中还可能引用未定义的外部符号，要留待链接阶段处理

4. 链接 .o -> 可执行程序
将各个 .o 与所需的库文件合并为可执行文件，核心工作是符号解析（匹配函数/变量引用）和重定位（确定并修正最终的地址引用）
